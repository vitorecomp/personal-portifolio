# Design System: cases.vitorx86.dev (`personal-portifolio`)

## Overview

**Creative North Star: "CYBR_ // Cyber Brutalism for Systems & Open Source"**

This site is the project portfolio and documentation companion to [vitorx86.dev](https://vitorx86.dev). It pulls live `README.md` documentation and repository metadata from [`github.com/vitorecomp`](https://github.com/vitorecomp) and presents them inside a Cyber-Brutalist architectural shell:

- **Exposed Structural Grids & `0px` Geometry**: Every module sits inside an exposed `1px solid` orthographic grid cell (`#DCDCE5` on light `#F5F5F8`, `#262636` on dark `#09090D`) with zero border radius (`0px`), chamfered section dividers, and `+` crosshair registration marks.
- **Towering Display + Razor Monospace**: Condensed uppercase geometric headlines (`Space Grotesk` / `JetBrains Mono`, `font-weight: 700`, tight tracking) paired with monospace technical telemetry (`SYS.TIME`, `//SCN_01`, `/01`..`/06` index numbers).
- **High-Contrast Accents**: Stark Black (`#09090D`), Electric Cyber Violet (`#7C3AED` / `#8B5CF6`), and Acid Lime (`#BEF264` / `#D9F99D`) carry all interactive states, directional `↗` arrows, coordinate callouts (`X/Y/Z`), and `ALL SYSTEMS OPERATIONAL ●` telemetry bars.
